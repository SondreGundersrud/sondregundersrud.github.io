# JS1 - Portfolio 1 CA

Purpose of this project is to simulate a e-commerce/store while getting products from an API.

## Description

The website will allow the user simulate the experience of browsing and shopping different products, adding the selected item into a cart.
Adding products to the cart will calculate and list up every item that has been added. The total price should adjust based on what items that are put into the cart.

- A broad selection of products will be presented.
- Clickable products, that show specific product detail. The product page will allow the user to add item to cart and the cart inventory will be updated.
- Opening cart will show list of ordered items, and total price.
